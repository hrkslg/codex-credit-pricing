# Codex 积分价格：1 积分值多少钱、各模型怎么扣、额度见底后怎么补更划算

搜「Codex 积分价格」的人，想知道的通常不是一句"按 token 计费"。真正的疑问是三个：跑一次重构大概扣多少积分？这些积分折算成人民币是多少？额度见底了，是买积分、升级套餐，还是换个渠道拿额度更划算。

这三个问题得分开答。

## 一、费率卡上没有"积分单价"这一行

OpenAI 的 Codex 费率卡只写了每个模型每百万 token 扣多少积分，没有印"1 积分 = 多少美元"。严格讲，官方没有公布过积分单价。

但费率卡可以反推。第三方对费率卡的换算是：每个模型的积分费率，恰好等于它 API 标价除以 0.04。GPT-6 Astra 的 API 输入价是每百万 token 10 美元，费率卡上对应 250 积分，一除就是 0.04。按这套算法，**1 积分对应 0.04 美元的 API 等价用量，100 积分约 4 美元**。

这是推算，不是官方标价，但拿来做预算足够用。官方自己给的参考值是：一个典型的 GPT-5.6-Sol 任务消耗 5 到 40 积分，折算下来大约 0.2 到 1.6 美元。如果是小改动，落在区间下沿；让它啃一个大文件加跑测试，就会往上跑。

## 二、积分是按 token 扣的，不是按条数

2026 年 4 月 2 日，Codex 的计费方式从"按消息条数"改成对齐 API 的 token 用量，新老 Plus、Pro、ChatGPT Business 以及新的 Enterprise 方案同时生效。4 月 23 日，这套规则又扩展到当时已存在的 Enterprise、Edu、Health、Gov 和 ChatGPT for Teachers。

改完之后，一次任务扣多少积分，取决于三种 token 的搭配：

- 输入 token
- 缓存输入 token
- 输出 token

费率卡里的规律相当整齐：输出费率是新输入的 6 倍，缓存输入是新输入的 1/10，官方另外注明 Codex 不收缓存写入的费用。

缓存这条对实际花费影响最大。同一个会话里连续干活，重复的上下文按十分之一算；每个任务都新开一个会话，等于把同样的上下文反复按原价买。如果非要记一条省钱规则，记这条比记任何一个模型名都有用。

输出最贵的另一面是：让 agent 只输出 diff，别复述整个文件。改动一个大文件时，这个习惯的差别很直观。

Sol、Terra、Luna 三档之间大约差 5 倍，这个倍差比大部分人直觉里的差距大。格式化、补注释、跑测试这类机械活丢给 Luna，和 Sol 的产出差别有限，费率却差 5 倍。默认用 Terra、机械活下沉 Luna、只有强推理才上 Sol，是比较常见的用法。

几条容易踩的细节：Fast mode 在支持的模型上扣得更快；代码审查用的是 GPT-5.3-Codex；GPT-5.4 和 GPT-5.4 mini 已在 2026 年 8 月 31 日从 Codex 中退役，官方建议替代为 GPT-5.6 Terra 和 GPT-5.6 Luna；GPT-5.5 Cyber 属于 Daybreak / Trusted Access for Cyber 项目内的模型，普通账号不一定见得到。

还有一点常被忽略：Codex、ChatGPT Work、ChatGPT for Excel 和 Workspace Agents 共用同一个 agentic 积分池。同时开着几个功能用，消耗是叠加的。

## 四、额度用完以后的三条路

订阅自带的额度先扣，用完才轮到积分。Plus 和 Pro 的额度按 5 小时窗口计算，另外可能叠加周上限。

撞到上限时，实际有三条路：

1. **等窗口恢复**。不花钱，但开发节奏会断。
2. **单独买额外积分**。官方明确支持 Plus 和 Pro 用户达到用量限额后购买积分继续工作，不必升级套餐。Business / Enterprise / Edu 侧对应的是买工作区积分。
3. **升档**。ChatGPT Go 是 8 美元/月，Plus 是 20 美元/月，Pro 从 100 美元/月起，Pro 档的 Codex 用量是 Plus 的 5 倍，更高档位可以到 20 倍。

判断标准其实不复杂：偶尔一两天撞顶，买积分。每周都撞顶且都是重推理任务，升档才划算。官方的限时活动也要留意时效——页面上曾标注某个档位享受双倍 Codex 额度，活动截止到 2026 年 5 月 31 日。

## 五、官方侧的成本参考和一个现实门槛

费率卡里给了一个整体数字：Codex 平均每个开发者每月大约 100 到 200 美元。波动来自模型选择、同时运行的实例数、自动化程度和使用强度。

这个数字对国内的独立开发者不太友好，而且门槛不只在价格——直接买 Codex 积分需要能正常支付 OpenAI 的账户环境，这一步就卡住了相当一部分人。

## 九、几个高频问题

**积分会过期吗？** 官方费率卡里没有说明有效期，我也没找到能确认的说法，不做推测。

**没有 Plus 套餐能单买积分吗？** 官方表述是"达到用量限额后可以购买额外积分"，也就是购买入口挂在现有套餐上。想靠纯买积分绕开订阅，目前没有依据。

**买积分和升档哪个便宜？** 用你最近一周的实际消耗去乘费率卡。一次 Sol 任务 5 到 40 积分，按 1 积分 0.04 美元算，一天二十次任务就是 4 到 32 美元。如果这个量是常态，升档通常比零散买积分划算。

**Fast mode 值不值？** 它按更高费率扣积分。只在确实卡在交互速度上的场景用，日常任务开着等于主动加价。

**为什么账单数字和估算差很多？** 大概率是输出 token 和缓存命中的比例问题。输出是新输入的 6 倍计价，缓存是新输入的 1/10，两头一拉，同样的任务量可以差出好几倍。

## 写在最后

Codex 积分价格这件事，真正的答案不是某一个数字，而是一条换算尺和一个使用习惯：1 积分约等于 0.04 美元的 API 等价用量，能省的部分主要藏在缓存命中和模型选择里，而不是藏在哪个渠道的折扣里。折扣只是把同样的用量买得更便宜，习惯决定的是你本来要花多少。

至于要不要走第三方渠道，判断依据其实很朴素：你卡的是钱，还是卡的是支付这一步。前者先调模型和缓存，后者再考虑渠道。
